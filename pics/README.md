# Your pictures

Put images in the category folders (`classic`, `rare`, `anime`, `cyber`, `space`, `pixel`, `art`, `crypto`).
JPG, PNG, WEBP, GIF or SVG. Then run from the repo root:

    node scripts/build-pics.mjs

and commit/push `pics/` + `data/pics.json`. Prefix a file name with `featured-` to show it in the hero.
